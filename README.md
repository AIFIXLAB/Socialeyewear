# Social Eyewear Smart Optic (v2)

เว็บแอปร้านแว่นแบบออนไลน์+ออฟไลน์: Sales Studio, ลูกค้า (ความยินยอม + ประวัติค่าสายตา), สินค้า (ราคา/ต้นทุน/สต็อก),
ใบเสนอราคา (พิมพ์/PDF/CSV), ภาพรวมยอดขาย, ร้านหลายพนักงานพร้อมบทบาท

## 1) ฐานข้อมูล Supabase
1. SQL Editor → ถ้าเคยรัน schema เวอร์ชันแรก/starter เดิมแล้วมี error เรื่อง shop_id ให้รัน `supabase/reset_dev.sql` ก่อน (ลบข้อมูลทั้งหมด ใช้เมื่อยังไม่มีข้อมูลจริง)
2. วางเนื้อหา `supabase/schema.sql` แล้วกด Run (รันซ้ำได้)
3. แก้ `config.js` ให้เป็น Project URL และ publishable key ของโปรเจกต์ (ใส่ไว้ให้แล้ว)

## 2) เผยแพร่เว็บ
อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub → Vercel → Import → Framework Preset = Other (ไม่ต้องมี Build Command)
ใช้กับ Netlify, Cloudflare Pages, GitHub Pages ได้เช่นกัน

## 3) เริ่มใช้งาน
1. เปิดเว็บ → ตั้งค่า → "สมัครบัญชีใหม่" (ถ้า Supabase เปิดยืนยันอีเมล ให้กดลิงก์ในอีเมลก่อน) แล้วเข้าสู่ระบบ
2. กด "สร้างร้าน" คุณจะเป็นเจ้าของร้านโดยอัตโนมัติ
3. เพิ่มพนักงาน: ให้พนักงานสมัครบัญชีเอง แล้วเจ้าของใส่อีเมลของเขาในหน้าตั้งค่า เลือกบทบาท
4. สินค้า → "เพิ่มสินค้าตัวอย่าง" หรือเพิ่มเอง
5. เมื่อทุกคนมีบัญชีครบ แนะนำปิด "Allow new users to sign up" ใน Supabase

## บทบาท
- เจ้าของ: ทุกอย่าง + จัดการพนักงาน
- ผู้จัดการ: ลบข้อมูล, ดูต้นทุนสินค้า, ดู audit log (ผ่าน SQL)
- พนักงาน: เพิ่ม/แก้ลูกค้า ค่าสายตา สินค้า ใบเสนอราคา แต่ลบไม่ได้

## ออฟไลน์
ข้อมูลบันทึกในเบราว์เซอร์ก่อนเสมอ เน็ตกลับมาจะซิงก์เอง (ดึงจากเซิร์ฟเวอร์ก่อน แล้วส่งที่แก้ในเครื่อง)
ยอดรวมและเลขที่ใบเสนอราคาถูกคำนวณ/ออกโดยฐานข้อมูล จึงอาจเห็นเลขที่หลังซิงก์ครั้งแรกเท่านั้น
ต้องเปิดเว็บออนไลน์อย่างน้อยหนึ่งครั้งเพื่อให้แคชไฟล์ ก่อนจึงเปิดออฟไลน์ได้

## ทดสอบในเครื่อง
ห้ามดับเบิลคลิก index.html ให้รัน `npx serve .` หรือ `python -m http.server 8080` แล้วเปิด http://localhost:8080

## ข้อควรระวัง
- แก้ล่าสุดชนะ: ถ้าสองเครื่องแก้รายการเดียวกันพร้อมกัน ฉบับที่ซิงก์ทีหลังจะทับ
- รายการที่ฐานข้อมูลปฏิเสธ (เช่น พนักงานพยายามลบ) จะขึ้น "ผิดพลาด" ในแถบซิงก์ และไม่ถูกส่งซ้ำจนกว่าจะแก้ไขรายการนั้น
- ค่าสายตาเป็นข้อมูลสุขภาพ ตรวจ PDPA และสิทธิ์พนักงานก่อนใช้กับลูกค้าจริง
- ข้อมูลที่ยังไม่ซิงก์อยู่ในเบราว์เซอร์ของเครื่องนั้น ใช้ปุ่ม "สำรองข้อมูล" ในหน้าตั้งค่าได้
- ห้ามใส่ secret key (sb_secret_...) / service_role ในโปรเจกต์นี้
- เวอร์ชันนี้ใช้ร้านแรกที่บัญชีเป็นสมาชิก (ยังไม่มีตัวสลับร้าน)
